# 🎬 MyVideoApp - 短视频社交平台

一个功能完整的短视频社交网站，UI 美观，功能强大。

## ✨ 功能一览

- 📱 手机号注册/登录
- 🔗 微信 / QQ 第三方登录（模拟）
- 🎞️ 上下滑动刷视频（自动播放）
- ❤️ 点赞 / ⭐ 收藏 / 💬 评论
- 📤 发布视频（支持封面上传）
- ✉️ 私信聊天（实时轮询）
- 👤 个人主页（改头像 / 改昵称 / 改简介）
- 📡 开直播（摄像头捕获 + WebRTC）
- 👥 关注 / 粉丝系统
- 🔔 通知系统
- 🎨 现代暗色主题 UI + 渐变

## 🚀 快速启动

```bash
# 1. 确保已安装 Node.js (>=14)
node -v

# 2. 进入项目目录
cd MyVideoApp

# 3. 启动服务（零依赖，无需 npm install）
node server.js
```

浏览器打开：**http://localhost:3000**

## 📁 项目结构

```
MyVideoApp/
├── server.js          # 后端服务器（零依赖）
├── package.json
├── README.md
├── data/              # 数据自动存储
└── public/
    ├── index.html     # 主页面
    ├── css/style.css  # 样式
    └── js/app.js      # 前端逻辑
```

## 📦 部署说明

- 数据以 JSON 文件持久化到 `data/db.json`，无需安装数据库
- 生产环境建议配合 Nginx 反向代理
- 默认端口 3000，可通过 `PORT` 环境变量修改
